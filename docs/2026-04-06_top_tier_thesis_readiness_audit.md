## 8. 参考论文适配性审计

### 8.1 `2304.03442v2` 的可借鉴点

该论文为 `Generative Agents: Interactive Simulacra of Human Behavior`。

对本项目最有价值的借鉴不是“社会模拟”本身，而是三层 agent 结构思想：

- memory
- reflection
- planning

其记忆检索思想可以抽象表示为：

\[
\text{score}_i=\alpha_r \cdot \text{recency}_i+\alpha_i \cdot \text{importance}_i+\alpha_s \cdot \text{relevance}_i
\]

对本项目的启发是：

- 论文写作中可以把当前系统解释为一种面向游戏任务的“受约束生成式智能体”
- 但必须诚实指出：当前项目并未完整实现该论文中的全量记忆流评分检索架构，而是实现了更偏工程可控的 `ContextManager + Summarizer + GoalManager + DecisionEngine`

### 8.2 `2502.19920v2` 的可借鉴点

该论文为 `Pokémon Red via Reinforcement Learning`。

它提供了三个非常关键的对照维度：

1. 把 Pokémon Red 明确定义为长时序、高探索难度、多任务耦合环境
2. 给出 MDP、PPO、奖励塑形等标准实验写法
3. 明确指出长篇游戏环境中的探索、奖励脆弱性和分层规划难题

对本项目的价值主要在于：

- 可以用来证明“Pokemon Red 作为长时任务智能体研究环境，本身是合理且有研究意义的”
- 可以用来帮助论文引入数学化问题定义与实验写法
- 但不能直接用作你项目结果强度的替代证明，因为你的系统不是 DRL 训练代理，而是在线 LLM 驱动、带运行时保护层的混合式 agent

### 8.3 参考论文适配结论

- 这两篇论文都很适合作为写作风格和理论定位参考
- 它们不适合被用来夸大本项目结果
- 最合理的做法是：
  - 用 `Generative Agents` 支撑 agent 结构理论
  - 用 `Pokémon Red via Reinforcement Learning` 支撑环境复杂性、长时任务和实验写法
